# Flexbox-LandingPageProject

I'll be creating an entire web page from scratch using a design provided for Odin project. The design provided comes in form of 2 images, one shows the complete 
web page and the other has the details of colors and fonts to be use. 

It's not neccesary to match every single pixel from the design, and I'm free to personalize the page. 

My LandingPageProject is done! I personalized the webpage with some chess content. I included images of the chess pieces in case someone doesn't know them, along 
with a quote from a Former World Champion below. The webpage was built using the elements provided by The Odin Project course, plus a help from Google to 
quickly find codes that are easy to forget in the moment.
